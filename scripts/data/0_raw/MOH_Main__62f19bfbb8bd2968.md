### பொது சுகாதார சேவைகள்

[ காசநோய் கட்டுப்பாடு மற்றும் இருதய நோய்களுக்கான தேசிய செயல்திட்டம்  ](https://www.nptccd.health.gov.lk/) [ தேசிய டெங்கு ஒழிப்பு பிரிவு  ](http://www.dengue.health.gov.lk/) [ பாலியல் தொற்று மற்றும் எயிட்ஸ் கட்டுப்பாட்டுக்கான தேசிய செயல்திட்டம்  ](https://www.aidscontrol.gov.lk/index.php?lang=en) [ யானைக்கால் நோய் எதிர்ப்புப் பிரச்சாரம்  ](http://www.filariasiscampaign.health.gov.lk/) [ தொழுநோய் எதிர்ப்புப் பிரச்சாரம்  ](https://www.leprosycampaign.health.gov.lk/index.php/en/) [ மலேரியா எதிர்ப்புப் பிரச்சாரம்  ](http://www.malariacampaign.gov.lk/en/) [ தனிமைப்படுத்தல் பிரிவு  ](https://www.health.gov.lk/ta/public-health-services/) [ ஊட்டச்சத்து பிரிவு  ](https://nutrition.health.gov.lk/english/) [ குடும்பச் சுகாதாரப் பணியகம்  ](https://fhb.health.gov.lk/index.php/en/) [ சுகாதார ஊக்குவிப்புப் பணியகம்  ](https://www.hpb.health.gov.lk/en) [ இளைஞர்கள்இ முதியவர்கள்இ ஊனமுற்றவர்கள் மற்றும் இடம்பெயர்ந்தவர்கள்  ](https://www.health.gov.lk/ta/public-health-services/) [ பெருந்தோட்ட மற்றும் பெருநகர சுகாதாரப் பிரிவு  ](https://www.health.gov.lk/ta/public-health-services/) [ பொதுச் சுகாதாரத்தைப் பராமரித்தல்  ](https://www.health.gov.lk/ta/public-health-services/) [ தொற்றா நோய்ப் பிரிவு  ](https://www.ncd.health.gov.lk/index.php?lang=en) [ புற்றுநோய் ஒழிப்புக்கான தேசிய செயல்திட்டம்  ](https://www.nccp.health.gov.lk/) [ உளநல சுகாதாரப் பணியகம்  ](http://www.mentalhealth.health.gov.lk/index.php?lang=en)
